1. Chuẩn bị & cách chạy (người dùng)

Điều kiện trước khi chạy
  • Extension đã load unpacked từ thư mục gốc repo (có manifest.json).
  • Đã đăng nhập Shopee Seller hoặc BigSeller — mở trang sửa/chi tiết sản phẩm.
  • Tab Gemini (gemini.google.com/app) — extension sẽ mở/focus nếu chưa có.
  • Tab Shopee consumer (shopee.vn, không phải banhang.shopee.vn) — dùng để crawl tìm kiếm.
  • Form sản phẩm đã có tiêu đề hoặc mô tả (extension đọc từ form, không dùng danh sách «Tên SP của tôi» trên trang search).

Các bước thao tác

  1. Reload extension trên chrome://extensions sau mỗi lần sửa code.
  2. Mở trang sửa sản phẩm trên Shopee Seller hoặc BigSeller.
  3. Tìm thanh công cụ neo cạnh vùng mô tả — bấm nút Tự động tối ưu.
  4. Overlay Tự động tối ưu SEO hiện tiến trình; tab Gemini và tab Shopee search sẽ được điều khiển tự động.
  5. Chờ pipeline hoàn tất (~ vài phút tùy số từ khóa). Khi xong, tiêu đề/mô tả mới được điền vào form — kiểm tra và Lưu trên Shopee/BigSeller.
  6. Nếu Shopee hiện CAPTCHA trên tab tìm kiếm: giải CAPTCHA thủ công, rồi bấm Tiếp tục trên overlay.
  7. Muốn dừng giữa chừng: bấm Hủy.

(Tuỳ chọn) Vào Cài đặt extension → Tự động tối ưu SEO để chỉnh số từ khóa, delay crawl, prompt Gemini.

SW Service worker là orchestrator — điều phối tuần tự, một tab search duy nhất, không crawl song song nhiều từ khóa. Timeout toàn pipeline: 15 phút. Chờ CAPTCHA tối đa 10 phút.

3. Pipeline 4 giai đoạn (chi tiết code)

0

UI Bấm «Tự động tối ưu»

src/content/shared/panel.js → handleOptimize():

  • Gọi adapter.extract() + extractIds() → payload: title, description, shopName, itemId, shopId, platform.
  • Hiện overlay qua showOptimizeProgress() (optimize-progress.js).
  • Gửi message OPTIMIZE_PRODUCT tới SW qua sendMessage().
1

Gemini Bước 1 — Gợi ý từ khóa

src/background/service-worker.js → handleOptimizeProduct():

  • Đọc settings từ getSettings().
  • buildKeywordPrompt(product, settings) — optimize-prompts.js; biến: {title}, {description}, {shopName}, {language}.
  • sendGeminiSchemaPrompt({ expectedSchema: 'keywords' }) → tab Gemini.
  • Content Gemini: điền prompt, bấm Send, response-tracker.js poll đến khi có JSON hợp lệ.
  • parseGeminiKeywordsJson() → mảng keywords; cắt tối đa optimizeMaxKeywords (mặc định 8).

Đầu ra mong đợi: {"keywords":["cụm 1","cụm 2",…]}

2

Shopee Bước 2 — Crawl SERP từng từ khóa

openOrReuseSearchTab() — tìm tab shopee.vn/search hoặc tab consumer Shopee; nếu không có thì tạo mới.

Vòng lặp for (keyword of keywords):

  • Gửi progress: Tìm kiếm trang 1 (i/n): «keyword».
  • navigateSearchTabToKeyword() — SW dùng chrome.tabs.update (không location.assign trong content script).
  • crawlKeywordOnSearchTab() → message SHOPEE_SEARCH_CRAWL với skipNavigate: true.
  • Content search-crawl-runner.js crawl trang 1, trả competitors[] + sourcePosition.
  • Delay giữa từ khóa: optimizeBetweenKeywordDelayMs (mặc định 3500 ms).

Nếu tổng đối thủ crawl được = 0 → pipeline dừng với lỗi (không gọi Gemini bước 2).

3

Gemini Bước 3 — Phân tích & viết lại

  • buildAnalysisPrompt({ ...product, crawlResults }, settings) — chèn {sourcePositionsBlock} và {competitorsTsv} (TSV từ OPTIMIZE_SERP_COLUMNS).
  • sendGeminiSchemaPrompt({ expectedSchema: 'product' }).
  • parseGeminiProductJson() → { title, description }.
  • sanitizeRewrittenProduct() — lọc tên shop, ký tự không hợp lệ.
4

UI Bước 4 — Áp dụng vào form

  • applyToSellerTab(sellerTabId, data) → message APPLY_PRODUCT tới adapter Shopee/BigSeller.
  • Focus lại tab seller.
  • Progress: Đã áp dụng tiêu đề và mô tả mới vào form + done: true → overlay đóng.

4. Chi tiết crawl từng từ khóa

File: src/content/shopee/search-crawl-runner.js — hàm crawlKeywordSearch()

#Bước nội bộMô tả
1 setOptimizeCrawlActive(true) Báo similar-products-research.js đang crawl — không reload «Tên SP của tôi» khi URL đổi keyword.
2 navigateToKeywordSearch(..., skipNavigate) Khi skipNavigate: true (SW đã navigate): chỉ kiểm tra URL khớp keyword + sleep settle (≥ 3000 ms). Không gọi location.assign.
3 detectShopeeCaptcha() Phát hiện iframe captcha / text xác minh. Trả { status: 'captcha' } → SW chờ user bấm Tiếp tục.
4 waitForKeywordSearchFresh(keyword) Chờ URL ?keyword= khớp; scroll lên đầu; chờ DOM kết quả mới (tránh đếm thẻ SP cũ từ keyword trước). Tối đa ~45 s chờ URL; ~18 s chờ DOM fresh.
5 waitForProductCardsReady(keyword, minProductCards) Poll thẻ SP — mặc định cần ≥ 55 thẻ, ổn định 5 vòng poll liên tiếp (mỗi 1 s). Timeout 120 s → throw nếu chưa đủ.
6 slowScrollPageOne() Scroll từng bước 400 px, delay optimizeScrollStepDelayMs (mặc định 900 ms). Chỉ kết thúc khi ≥ min thẻ + chạm đáy trang + ổn định 5 vòng, hoặc timeout 150 s.
7 scrapeCurrentPage() similar-products-scraper.js — đọc thẻ SP visible trên DOM.
8 Lọc & map filterByMinSold (≥ optimizeMinSold), dedupeByTitle, mapRowsToOptimizeSerp → cột TSV gửi Gemini.
9 resolveSourcePosition() Tìm vị trí SP gốc (theo itemId hoặc so khớp tiêu đề form) trên trang 1.
10 setOptimizeCrawlActive(false) Kết thúc crawl keyword (trong finally).

Navigate từ Service Worker

navigateSearchTabToKeyword() trong SW:

  1. chrome.tabs.update → URL https://shopee.vn/search?keyword=…
  2. waitForTabComplete (tối đa 35 s)
  3. Sleep ≥ max(navigateDelayMs, 4000 ms)
  4. ensureTabReady — ping content script Shopee
  5. Sleep thêm 1500 ms

9. CAPTCHA & Hủy / Tiếp tục

CAPTCHA

  1. Crawl phát hiện CAPTCHA → trả status: 'captcha'.
  2. SW set optimizeState.waitingCaptcha = true, overlay hiện nút Tiếp tục.
  3. User giải CAPTCHA trên tab shopee.vn/search, bấm Tiếp tục.
  4. OPTIMIZE_RESUME → waitForOptimizeResume() resolve → crawl lại cùng keyword (không nhảy sang keyword khác).

Hủy

  • Overlay → OPTIMIZE_CANCEL → SW set cancelled: true.
  • Tab Shopee search nhận cancel → AbortController abort crawl đang chạy.
  • Pipeline trả lỗi «Đã hủy pipeline».

10. Lỗi thường gặp

Thông báoNguyên nhân / cách xử lý
Pipeline chưa sẵn sàng — Reload extension Service worker chưa đăng ký (status 15) hoặc mất kết nối. Reload trên chrome://extensions.
Gemini không trả JSON keywords/product hợp lệ Gemini trả markdown hoặc text ngoài JSON. Thử lại; kiểm tab Gemini đang mở.
Không crawl được đối thủ SERP (bảng TSV trống) CAPTCHA, DOM chưa load, hoặc selector Shopee đổi. Giải CAPTCHA, tăng delay, reload extension.
Chỉ thấy X/55 thẻ SP Trang chưa tải đủ — tăng navigate delay; đợi mạng ổn định.
Pipeline tối ưu đang chạy Chỉ một pipeline/lúc. Hủy run cũ hoặc đợi xong.
Hết thời gian pipeline (15 phút) Quá nhiều keyword / mạng chậm / CAPTCHA lâu. Giảm optimizeMaxKeywords.
Lưu ý CSP trên Gemini Console có thể báo lỗi CSP từ googleadservices.com / GTM khi extension click Send — đây là noise từ trang Google, không phải lỗi extension.
