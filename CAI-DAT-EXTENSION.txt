CÁCH TẢI TIỆN ÍCH BIGSELLER AI (Chrome / Edge)
============================================

Cách 1 — Thư mục gốc dự án (sau khi chạy npm run build):
  Chọn thư mục:  ...\bigseller-AI
  (phải có file manifest.json ngay trong thư mục này)

Cách 2 — Thư mục build (luôn đúng):
  Chọn thư mục:  ...\bigseller-AI\dist

Các bước:
  1. Mở terminal trong dự án, chạy:  npm install   (lần đầu)
  2. Chạy:  npm run build
     (mỗi lần build tự tăng phiên bản patch: 1.0.0 → 1.0.1 → …)
  3. Chrome → chrome://extensions  (Edge → edge://extensions)
  4. Bật "Chế độ nhà phát triển"
  5. "Tải tiện ích đã giải nén" → chọn một trong hai thư mục ở trên

Nếu báo "Tệp kê khai bị thiếu":
  → Chưa chạy npm run build, hoặc chọn sai thư mục (thiếu manifest.json).
